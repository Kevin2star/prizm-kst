역할: Supabase Edge Function + Gemini 연동 엔지니어.
선행 단계: 06_frontend_upload_layout.txt 까지 업로드 흐름이 있어야 한다.
이번 단계 목표: 업로드된 항목마다 태깅과 임베딩을 비동기로 수행한다. (F3)
다음 단계: 08_grouping_comparison.txt

================================================================
제품 컨텍스트
================================================================
업로드된 항목마다 두 가지를 수행한다.
1) 태깅 (gemini-2.5-flash): 핵심 주제, 접근 방식, 사용 기술/관점을 3~5개 키워드로 추출
2) 임베딩 (gemini-embedding-001, 768차원): 벡터 생성 후 DB 저장

공식 Java SDK 대신 Edge Function에서 fetch 로 REST를 직접 호출한다.
  - 태깅: generateContent
  - 임베딩: embedContent
GEMINI_API_KEY는 Functions secret. 프론트에서 Gemini를 호출하지 않는다.

================================================================
파이프라인
================================================================
04단계에서 만들어 둔 analyze-artifact / waitUntil 파이프라인을 구현한다.

흐름:
  업로드 API는 즉시 PENDING 반환
  → 백그라운드로 파이프라인 시작, status=PROCESSING
  → 태깅 API
  → 임베딩 API
  → tags, embedding 저장, status=READY
  → (그룹핑은 08단계이므로 지금은 호출 자리만 주석/빈 메서드로 남긴다)

실패 시 status=FAILED, 에러 로그. 업로드 자체는 롤백하지 않는다.

================================================================
태깅 프롬프트 규칙
================================================================
모델에게 JSON만 반환하라고 명시한다. 마크다운 코드펜스를 금지한다.
입력: title, content, school, major
출력 스키마:
  {
    "tags": ["키워드1", "키워드2", "키워드3"]
  }
- 3~5개
- 한국어 명사구
- 전공명을 태그로 그대로 넣지 말고, 내용에서 나온 주제/접근/기술을 뽑는다.

파싱 실패 시 재시도 1회, 그래도 실패하면 tags=["미분류"] 로라도 READY에 가깝게
만들되, embedding이 없으면 FAILED가 맞다. 임베딩이 있어야 08단계에서 그룹핑이 된다.

================================================================
임베딩
================================================================
- 모델: gemini-embedding-001
- 차원: 768 (output dimensionality 지정)
- 임베딩 입력 텍스트: title + "\n" + content (너무 길면 앞부분 truncate)
- 결과는 JSON 배열 문자열로 Artifact.embedding에 저장
- 코사인 유사도 유틸(double[] a, double[] b)을 미리 만들어 둔다. 08단계에서 사용.

================================================================
설정 및 주의
================================================================
- GEMINI_API_KEY 는 Functions secret. 로그에 키를 남기지 않는다.
- 직렬로 태깅+임베딩을 하면 5~10초 걸릴 수 있다. 그래서 반드시 백그라운드(waitUntil).
- 무료 티어 rate limit: 재시도는 짧게, 429면 로그 후 FAILED.
- 프론트에서 Gemini를 호출하지 않는다. Edge Function만 호출한다.

================================================================
하지 말 것
================================================================
- 그룹 생성, 비교 정리본 생성은 08단계다. 이 단계에서 다른 Artifact와 묶지 않는다.
- 벡터DB(Pinecone, pgvector 등)를 도입하지 않는다.
- Anthropic/Voyage를 추가하지 않는다. Gemini 단일 벤더.

================================================================
완료 기준
================================================================
- 텍스트를 올리면 수 초 뒤 Artifact.tags 와 embedding 이 채워지고 status=READY 가 된다.
- 업로드 HTTP 응답은 여전히 즉시 반환된다.
- 잘못된 API 키면 FAILED가 되고 서버가 죽지 않는다.
- 코사인 유사도 유틸 테스트 또는 수동 확인이 가능하다.
