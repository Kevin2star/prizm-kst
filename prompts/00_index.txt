KOSSCCHTHON — 단계별 구현 프롬프트 가이드
프로젝트: 협업 결과물 AI 자동 정리·시각화 플랫폼 (가칭 Prizm)

================================================================
한 줄 정의
================================================================
팀원을 초대한 공유 스페이스에 각자 결과물을 올리면, AI가 자동으로 분석·비교해
하나의 시각화된 정리본(마인드맵 트리)으로 만들어주는 협업 플랫폼.

================================================================
이 폴더를 쓰는 방법
================================================================
1. 01부터 13까지 번호 순서대로 사용한다. 앞 단계를 건너뛰지 않는다.
   이미 01~13이 끝난 뒤 DB만 바꿀 때는 14를 실행한다.
   Spring 백엔드 자체를 제거할 때는 15를 실행한다. 15가 끝나면 14는 쓰지 않는다.
   스페이스 화면을 NotebookLM 클론 HTML 레이아웃으로 바꿀 때는 16을 실행한다.
   마인드맵 노드 겹침·상세글 잘림·중복 입장 프로필·멤버 색 충돌은 16 뒤에 17을 실행한다.
2. 각 파일을 Cursor / Claude / ChatGPT 등 코딩 에이전트에 그대로 붙여넣는다.
3. 한 단계가 완료 기준을 통과한 뒤에만 다음 파일로 넘어간다.
4. 모든 프롬프트는 P0만 구현한다. P1(파일 업로드), P2(노드 수동 이동, 댓글)는 하지 않는다.
5. 03:00 시점에 P0가 다 안 되면, 단계 13의 다운그레이드 규칙을 따른다.
   (마인드맵 트리 → 그룹별 카드 목록)

17_mindmap_overlap_member_identity.txt
                               마인드맵 카테고리 겹침, 상세글 잘림,
                               동일 신원 재입장 시 멤버 중복 금지, TEAM 프로필 색 충돌 해소
                               (16 뒤에만 실행)

================================================================
기술 스택 (고정)
================================================================
백엔드   Supabase Edge Functions (Deno)
DB       Supabase Postgres (벡터는 JSON 컬럼)
실시간   Supabase Realtime (postgres_changes) + 3초 폴링 폴백
AI       Gemini 단일 벤더
         - 태깅·정리본: gemini-2.5-flash
         - 임베딩: gemini-embedding-001 (768차원)
프론트   React

벡터DB는 쓰지 않는다. 데모 규모(수십 건)에서는 전체 조회 후 코사인 유사도를
Edge Function에서 직접 계산한다.

================================================================
P0 기능 (반드시 구현)
================================================================
F1 스페이스 생성 및 6자리 코드 입장 (로그인 없음)
F2 결과물 업로드 (텍스트 직접 입력만)
F3 AI 태깅 + 임베딩
F4 그룹핑 및 비교 정리본 (공통점 / 차이점 / 비고 / 원본)
F5 마인드맵 트리 시각화 (접기/펼치기)
F6 실시간 동기화 (노드 추가 브로드캐스트)

================================================================
핵심 제품 주장 (구현·카피·데모에서 절대 흐리지 말 것)
================================================================
- 자료를 한 사람이 모을 필요가 없다. 각자 자기 것만 올리면 통합이 자동으로 일어난다.
- 아무도 "정리해줘"라고 요청하지 않았는데 화면이 스스로 갱신된다.
- 대화는 끝나면 사라지지만, 스페이스에 쌓인 관계망은 자산으로 남는다.
- 교류는 '만남'이 아니라 '결과물 간의 자동 연결'로 일어난다.
