================================================================
제품 컨텍스트
================================================================
시각화 구조:
  루트(스페이스 주제)
    → 그룹(자동 클러스터)
      → 4개 하위 노드: 공통점 / 차이점 / 비고 / 원본 목록
    → (그룹 없는) 단독 Artifact 잎 노드

GET /api/spaces/{id}/graph 가 이 트리의 단일 소스다.
프론트가 여러 API를 조합해 트리를 조립하지 않게 한다.

규칙:
- 그룹 없는 Artifact(groupId null)는 루트 직속 자식이다.
- PENDING/PROCESSING/FAILED 도 트리에 포함한다. 분석 중임을 화면에 보여야 한다.
- sourceArtifactIds는 "소스 N개 보기" 링크에 쓴다. 공통점/차이점/비고 모두 가진다.
- updated 플래그는 그룹이 마지막 5분 내 갱신되었으면 true 정도로 단순 구현한다.
  (프론트 10단계에서 "업데이트됨" 배지)

기존 GET /api/groups/{id}, GET /api/artifacts/{id} 는 유지한다.
그래프의 잎을 클릭하면 원문 단건 API를 호출한다.

================================================================
하지 말 것
================================================================
- 노드 x,y 좌표를 서버가 계산하지 않는다. 트리는 프론트가 접고 펼친다.
- force-directed 그래프용 nodes/edges 평 리스트를 만들지 마라. children 트리로 준다.
- 페이지네이션은 필요 없다. 데모 규모는 수십 건이다.

================================================================
완료 기준
================================================================
- 스페이스 하나 조회만으로 루트-그룹-4갈래-원본 트리를 그릴 수 있다.
- 단독 결과물과 그룹이 함께 내려온다.
- PENDING 항목도 누락되지 않는다.
