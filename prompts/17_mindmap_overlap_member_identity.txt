역할: React + d3 + Supabase Edge Function 엔지니어.
선행 단계: 01~16이 이미 끝난 상태. 스페이스 입장, 업로드, graph, d3 마인드맵, SourcePanel, 좌측 TEAM 아바타가 동작한다.
이번 단계 목표: 마인드맵 노드 겹침 해소, 상세글 잘림 해소, 동일 신원 재입장 시 멤버 중복 생성 금지, 팀 프로필 색 충돌 해소.
다음 단계: 없음. 버그픽스만 한다.

이 파일을 코딩 에이전트에 그대로 붙여넣는다. 구현하고 브라우저에서 확인한다. 프롬프트만 쓰지 말고 코드를 고친다.

================================================================
한 줄 정의
================================================================
펼친 마인드맵 카테고리 라벨이 서로 겹치지 않게 레이아웃을 조율하고,
원문/상세 패널 본문이 화면 밖으로 잘리지 않게 컨테이너 수치를 고치고,
같은 방·같은 ID(신원)로 다시 들어오면 프로필을 새로 만들지 않으며,
사이드바 멤버 원 색이 서로 구분되게 한다.

================================================================
현재 상태 (As-Is) — 재현된 버그
================================================================
1) 마인드맵 카테고리 겹침
   파일: frontend/src/components/MindmapCanvas.jsx
   drawTree()에서 d3.tree().nodeSize([56, 220]) 고정.
   부모 노드는 라벨을 왼쪽(text-anchor end), 자식은 오른쪽(start)으로 그린다.
   rect 높이 32, 가로 간격 220px, 세로 간격 56px.
   한글 긴 라벨(예: "알레르기 메뉴 표시 표준", "키오스크 앞 이중 줄 없애기 · 실패")이
   형제 가지의 "원본 목록" 등과 시각적으로 겹친다.
   clip()으로 글자만 자르는 것으로는 겹침이 안 풀린다. 노드 박스끼리 충돌하지 않아야 한다.

2) 상세글이 화면에서 잘림
   노드 클릭 시 SourcePanel이 마인드맵 오른쪽 위에 오버레이된다.
   파일:
     frontend/src/components/SourcePanel.jsx
     frontend/src/pages/SpaceWorkspace.css  (.nlm-workspace .panel, .nlm-map-body)
     frontend/src/App.css (.panel, .body-text)
   .nlm-workspace 는 overflow: hidden.
   .nlm-workspace .panel 은 position:absolute; top/right/bottom:0; width: min(360px, 100%);
     overflow-y: auto; padding: 16px.
   제목·작성자·본문이 패널 오른쪽 끝에서 잘려 나온다.
   본문은 줄바꿈/말줄임이 아니라 컨테이너 너비·overflow 때문에 잘리는 형태다.

3) 같은 사용자가 같은 방에 다시 들어오면 프로필이 하나 더 생김
   POST /spaces/{code}/join (supabase/functions/prizm-api/index.ts) 가
   매번 members INSERT만 한다. 기존 행 조회/재사용이 없다.
   프론트 TEAM 목록(frontend/src/pages/SpacePage.jsx members useMemo)은
   memberId 기준으로만  Dedup 한다. 같은 닉네임이 다른 memberId면 원이 두 개다.
   세 번째 스크린샷처럼 "테스트"가 여러 개, 같은 사람이 원 여러 개로 쌓인다.

4) 프로필 색이 겹침
   colorForMajor(major) (MindmapTree.jsx)가 전공 문자열 해시 % 팔레트다.
   같은 전공이면 전부 같은 색. 다른 전공도 팔레트 7색이라 충돌한다.
   TEAM 아바타(SpacePage.jsx .nlm-member)도 이 함수를 쓴다.
   범례(전공 색)와 사람 프로필 색을 같은 해시로 묶지 말 것.
   사람 원은 멤버마다 다른 색이어야 한다.

목표 상태 (To-Be)
================================================================
A. 마인드맵 겹침
   - 펼친 상태에서 형제/사촌 노드의 rect·text가 겹치지 않는다.
   - nodeSize 세로·가로를 라벨 길이와 rect 높이에 맞게 키운다.
     권장 출발점: 세로(dx) 72 이상, 가로(dy) 280 이상. 겹치면 더 늘린다.
   - 긴 라벨은 한 줄로 밀어 이웃을 침범하지 말고, 필요하면 2줄 wrap + rect 높이 증가.
     wrap하면 nodeSize 세로도 그만큼 키운다.
   - 부모 왼쪽 라벨과 다른 가지 자식 오른쪽 라벨이 교차하지 않게
     수평 간격 또는 텍스트 배치를 조정한다.
   - 줌/팬은 유지한다. force-directed로 바꾸지 않는다.
   - 토글·클릭(ARTIFACT/소스 패널) 동작은 유지한다.

B. 상세글 잘림
   - SourcePanel 본문이 패널 안에서 줄바꿈되어 전부 읽힌다. 가로로 잘리면 안 된다.
   - 담는 태그(.nlm-workspace .panel, article, .body-text, h2)의
     width / max-width / padding / overflow 를 조절한다.
   - overflow-x: hidden 으로 글자를 자르지 말 것. overflow-y만 스크롤.
   - word-break: break-word; overflow-wrap: anywhere; white-space: pre-wrap;
   - 패널이 너무 좁으면 width를 360px에서 늘린다(예: min(420px, 42%)).
     box-sizing: border-box 로 padding이 너비를 초과하지 않게 한다.
   - 마인드맵 캔버스가 패널 아래로 가려지는 것은 허용. 글 잘림은 비허용.

C. 동일 신원 재입장
   - 같은 space + 같은 ID 정보면 members 행을 INSERT하지 않고 기존 행을 반환한다.
   - ID 정보 매칭 (대소문자·앞뒤 공백 정규화 후 비교):
       nickname + school + major 가 모두 같으면 동일인.
     요청 body에 memberId가 있고 그 멤버가 해당 space에 있으면 그 행을 우선 재사용.
   - 응답 형태는 지금과 같다: { memberId, spaceId, nickname, school, major }.
   - 프론트 JoinSpace / CreateSpace 세션 저장은 그대로. 받은 memberId만 쓰면 된다.
   - SpacePage TEAM 목록은 memberId가 달라도 위 신원이 같으면 원 하나.
     아티팩트 작성자 표시는 그대로 두되, 사이드바 원은 사람 단위로 유일.
   - 기존에 이미 중복 INSERT된 행은 마이그레이션으로 지우지 않아도 된다.
     UI·이후 join만 중복을 만들지 않으면 된다. unique 인덱스는 넣어도 되고,
     기존 중복 때문에 unique가 실패하면 조회 재사용만 하고 unique는 생략한다.

D. 프로필 색이 겹치지 않게
   - TEAM 아바타·채팅 이름 색은 멤버 고유 색. colorForMajor를 사람에게 쓰지 말 것.
   - 새 헬퍼 예: colorForMember(memberId 또는 nickname+school+major).
     스페이스 안 멤버 목록을 안정 정렬한 뒤 팔레트에서 서로 다른 인덱스를 할당.
     멤버 수가 팔레트보다 많으면 색상환에서 hue를 균등 분할해 근접한 두 원이
     같은 색으로 보이지 않게 한다. 해시 % 7색만 쓰지 말 것.
   - 현재 세션 멤버(.nlm-member.is-me) 흰 테두리·opacity는 유지.
   - 마인드맵 전공 범례와 노드 점(colorForMajor)은 전공 교류용으로 유지해도 된다.
     사람 원과 전공 점은 목적이 다르다.

완료 기준
================================================================
- 그룹을 펼쳐 4갈래(공통점/차이점/비고/원본)와 하위 아티팩트 라벨이 겹치지 않는다.
- 원문 패널에서 긴 한글 본문이 오른쪽에서 잘리지 않고 줄바꿈 + 세로 스크롤로 읽힌다.
- 같은 닉네임·학교·전공으로 같은 코드 join을 두 번 해도 members가 한 행이고,
  TEAM 원이 하나다. 세션 memberId는 기존 id다.
- TEAM 원에 서로 다른 사람이 있으면 원이 서로 다른 색이다. 같은 전공이어도 사람 색은 달라도 된다.
- 업로드, graph 갱신, 실시간, 소스 보기 클릭이 깨지지 않는다.
