================================================================
제품 컨텍스트
================================================================
필수 항목은 제목 + 본문 두 개뿐이다. 진입 장벽을 최소화한다.
업로드 즉시 분석 큐에 등록되고 처리 중 상태를 표시해야 하므로,
이번 단계부터 Artifact.status 를 PENDING 으로 저장한다.
실제 Gemini 호출은 07단계에서 붙인다.

================================================================
API 스펙
================================================================
POST /api/spaces/{spaceId}/artifacts
  request: {
    "memberId": 10,
    "title": "카페 대기열 재배치",
    "content": "피크타임 동선을 ..."
  }
  response (201, 즉시 반환): {
    "id": 101,
    "spaceId": 1,
    "memberId": 10,
    "title": "카페 대기열 재배치",
    "content": "...",
    "status": "PENDING",
    "tags": [],
    "groupId": null,
    "createdAt": "..."
  }
  규칙:
  - memberId가 해당 space에 속하지 않으면 403
  - title/content 공백이면 400
  - 파일 업로드(.txt, .md, 코드 파일)는 P1이므로 만들지 않는다.
  - 응답은 분석 완료를 기다리지 않는다. 즉시 PENDING으로 반환한다.
    (AI 지연 5~10초 때문에 화면이 멈추면 안 된다)

GET /api/spaces/{spaceId}/artifacts
  response: Artifact 목록 (최신순)
  - 마인드맵 이전에도 프론트가 목록을 확인할 수 있게 한다.

GET /api/artifacts/{id}
  response: 단건 조회. 원문 패널("소스 1개 보기")에서 사용한다.

================================================================
분석 스텁
================================================================
ArtifactService.create() 끝에서 AnalysisPipeline.enqueue(artifactId) 를 호출할 자리를 만든다.
지금은 아래 중 하나로 구현한다.
  A) @Async 메서드가 로그만 남기고 return
  B) TODO 주석이 있는 no-op 컴포넌트
07단계에서 이 메서드 안에 태깅·임베딩을 넣을 것이므로 시그니처를 고정한다.

  public void enqueue(Long artifactId) { ... }

================================================================
하지 말 것
================================================================
- Gemini API를 이 단계에서 호출하지 않는다.
- 그룹핑, 정리본 생성, WebSocket 브로드캐스트를 하지 않는다.
- multipart 파일 업로드를 구현하지 않는다. 텍스트만.

================================================================
완료 기준
================================================================
- POST 하면 Artifact가 PENDING으로 저장되고 201이 즉시 반환된다.
- GET 목록/단건이 동작한다.
- 잘못된 memberId/spaceId 조합은 막힌다.
- AnalysisPipeline.enqueue 호출 지점이 코드에 존재한다.
